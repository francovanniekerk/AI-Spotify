# Spotify AI Integration Breakdown

A simple static website created for my coursework. It explains how Spotify uses Artificial Intelligence, Machine Learning and Generative AI to personalise the listening experience.

## Topics Covered

- **Artificial Intelligence:** Spotify’s AI DJ.
- **Machine Learning:** Personalised music and podcast recommendations.
- **Generative AI:** DJ commentary and generated voice.

## Technologies Used

- HTML
- CSS
- Bootstrap 5

## Project Files

- `index.html` — The webpage content and structure.
- `style.css` — Custom styling for the webpage.

## Run Locally

1. Download the repository files.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in your browser.

An internet connection is required to load Bootstrap.

## Deployment

This project is prepared for deployment using GitHub Pages.
